Tudo muda, e o custo total não muda um centavo

105

4 → 1

523 → 520
pessoas: as duplicadas somem
CREATE OR REFRESH MATERIALIZED VIEW tarefas (
  CONSTRAINT achou_o_projeto
    EXPECT (projeto_id IS NOT NULL)
    ON VIOLATION FAIL UPDATE,
  CONSTRAINT pct_entre_0_e_100
    EXPECT (pct_concluido BETWEEN 0 AND 100)
    ON VIOLATION FAIL UPDATE
) AS SELECT … -- excel ∪ clickup ∪ msproject

Prompt 3 · a pergunta antes do código

De onde vem o histórico?

As ferramentas

measures:
  - name: spi
    expr: SUM(ev) / SUM(pv)
  - name: cpi
    expr: SUM(ev) / SUM(ac)
  - name: projetos_melancia
